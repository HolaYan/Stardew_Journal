## 下载与安装

当前版本 **2.0.0**，支持 **macOS 11 及以上**，同一安装包适用于 **Apple 芯片和 Intel Mac**。

1. 打开[最新 Release](https://github.com/HolaYan/Stardew_Journal/releases/latest)，在 **Assets** 中下载 **`Stardew-Journal-macOS-universal.zip`**。
2. 双击 ZIP 解压，打开解压后的文件夹。
3. 将 **`Stardew Journal.app`** 拖入访达的 **“应用程序”（Applications）** 文件夹。
4. 从“应用程序”打开 Stardew Journal，开始种下第一件待办。

**完整版已内置游戏素材和中文对白，不需要安装《星露谷物语》、Stardew Desk、Node.js 或开发工具。** 待办、农场、钓鱼、动物照料、烹饪和村民对白均可离线使用；实时天气需要联网。Release 中的 `Source code` 是开发源码，普通使用请选择上面的完整版 ZIP。

### 首次打开时遇到 macOS 提示

当前版本采用本地临时签名，**尚未经过 Apple 开发者公证**。首次打开可能出现“无法验证开发者”或“Apple 无法检查是否包含恶意软件”的提示。

如果你确认安装包来自本仓库的 Release，且愿意运行此版本：

1. 先尝试打开一次 App，关闭提示。
2. 在 macOS 13 及以上打开 **“系统设置 → 隐私与安全性”**，向下找到 Stardew Journal 的拦截提示，点击 **“仍要打开”**。
3. 在后续对话框中确认 **“打开”**，按系统要求完成认证。之后通常可以直接双击打开。

macOS 11／12 的对应入口是 **“系统偏好设置 → 安全性与隐私 → 通用 → 仍要打开”**。流程依据 Apple 的[当前说明](https://support.apple.com/zh-cn/102445)与 [macOS 11 说明](https://support.apple.com/zh-cn/guide/mac-help/mh40616/11.0/mac/11.0)。如果出现“已损坏”或“将损坏你的电脑”等其他提示，请先停止打开，并在 [Issues](https://github.com/HolaYan/Stardew_Journal/issues) 中提供系统版本和提示内容。

## 开始使用

1. 点击农田空地或 **“＋”**，填写待办和日期，选择一颗种子。
2. 在 **“下一周／一个月／三个月”** 中查看计划，点击待办文字可以编辑。
3. 完成时勾选方框，或点击田里的作物收获；对应作物会进入 **仓库**。
4. 点击屋子进入厨房，勾选 **“只看能做的”**，选择一道菜开始烹饪，再到 **冰箱** 查看成果。

首次打开是空白清单；想先体验一下，可以在设置中添加示例待办。

## 可以做什么

| 功能 | 用法 |
| --- | --- |
| 种下计划 | 按 7／30／90 天查看待办，填写分类、备注和重要标记；不同期限可选不同作物。三个范围都包含今天，未完成的逾期事项会保留。 |
| 经营小农场 | 点击农田、屋子、箱子、灶台和冰箱进入对应功能。完成待办就能收获，不需要等待游戏天数。 |
| 仓库与厨房 | 81 道原版食谱，现有食材来源支持其中 45 道。做菜扣除食材，成品进入冰箱；撤销烹饪可返还那次消耗的食材。 |
| 鱼塘休息 | 随机钓鱼或选择想遇见的鱼，成功后自动入仓。每天可玩多久由你设置：0–180 分钟，默认 10 分钟，0 表示关闭。 |
| 鸡舍与畜棚 | 鸡舍照料鸡和鸭，畜棚照料牛和羊；依次喂食、抚摸、收取蛋或奶，每只动物每天可领取一份。 |
| 村民来访 | 原版肖像和中文对白，可以指定角色、随机来访，或再聊一句。 |
| 桌面陪伴 | 自由调整窗口大小、切换小组件模式、窗口置顶；季节可按北半球现实月份自动变化，也可手动选择，设置城市后可显示实时天气。 |

关闭窗口后，点击菜单栏的 **小鸡** 可以重新打开。`⌘N` 新建待办，`⌘Q` 完全退出。这里的“小组件模式”是桌面小窗口，尚未接入 macOS 通知中心小组件。

## 待办保存在哪里？

所有待办和农场进度都保存在当前 Mac 本机，**不与 Apple“提醒事项”（Reminders）同步，也没有账号或云同步**。

```text
~/Library/Application Support/Meadow/state.json
```

目录沿用早期名称 Meadow，以保留已有存档。更新 App 不会覆盖这个独立的数据目录。设置中可以 **导出备份／导入备份**；导入会先校验，再由你确认替换当前数据。建议更新或换电脑前导出一份备份。

只有主动设置天气城市后，应用才向 Open-Meteo 查询天气；查询使用城市名称或所选城市坐标，不发送待办内容，也不使用系统定位。未设置城市或网络不可用时显示装饰天气。目前不包含系统提醒和开机自启动。
