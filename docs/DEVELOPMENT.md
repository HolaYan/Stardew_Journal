# Stardew Journal 开发文档

普通用户请从 [README](../README.md) 下载完整 App。本文用于源码开发、重新提取本机游戏素材和构建发布包。

## 开发环境

- macOS 和 Apple Command Line Tools，原生宿主使用 Swift / AppKit / WKWebView。
- Node.js（提供 `node` 与 `npm`）；项目不需要安装 npm 依赖。
- 浏览器预览命令需要 Python 3。
- 从无素材的源码开始构建，需要本机已安装的《星露谷物语》，以及 Stardew Desk 已生成的基础场景 PNG 缓存。详细路径见下文“本机游戏素材”。

应用的最低运行版本为 macOS 11。构建脚本分别编译 `arm64` 与 `x86_64`，再生成通用二进制；完整 Release 的接收者不需要开发环境或本机游戏安装。

## 构建、运行与打包

以下命令均在项目根目录执行：

```sh
# 若尚未安装 Apple Command Line Tools：
xcode-select --install

# 首次准备素材；默认读取本机 Stardew Desk 缓存与 Steam 游戏安装。
sh scripts/import-game-assets.sh

npm run check
npm test
npm run build
npm start
```

`npm run build` 生成 `dist/Meadow.app`；`npm start` 会重新构建并打开它。也可以双击根目录的 `启动Stardew Journal.command`。旧版启动脚本仍可使用；开发构建的包路径、可执行文件和数据目录沿用 Meadow，以保留既有计划。

```sh
npm run preview  # http://127.0.0.1:4173
npm run package  # 将已经构建好的 App 打包
sh scripts/package-source.sh
```

完整应用包为 `dist/Stardew-Journal-macOS-完整版.zip`，解压后包含 `Stardew Journal.app` 和 `打开说明.txt`。应用包包含运行所需的 `web/game-assets/`；打包脚本检查素材、通用架构和签名。构建目前使用本地临时签名，尚未进行 Developer ID 签名或 Apple 公证。用户首次打开的说明见 [README](../README.md#首次打开时遇到-macos-提示)。

源码包为 `dist/Stardew-Journal-source.zip`，不含游戏素材、构建目录或 App。GitHub 的自动 `Source code` 下载同样用于源码开发，不能代替完整 App。

## 种下计划

- 点击「种下新待办」，填写标题、日期、分类、备注，选择一颗种子，也可以标记重要。
- 「下一周 / 一个月 / 三个月」分别显示从今天起的 **7 / 30 / 90 天**，均包含今天。较长范围包含较短范围；未完成的逾期事项始终保留。超过 90 天的事项在「全部待办」中查看。
- 每件待办显示自己的作物图像。种植周期根据种下计划时的截止日期确定，之后不会因日期临近而自动换种子。
- 一周计划可选原版初次生长不超过 7 天、不能重复收获的作物；一个月计划可选初次生长 8–14 天、不能重复收获的作物；三个月计划可选能重复收获或初次生长至少 15 天的作物。
- 界面显示游戏中的真实生长天数。**7 / 30 / 90 天是待办计划范围，不是重新设定的游戏生长时间。** 小组件也不会要求你等待游戏天数：完成待办就能收获。
- 点击方框完成待办，点击文字编辑。每件已分配作物的待办完成时收获 **1 个对应作物**，不会因重复点击而重复入库。

顶部农场也可以直接操作：点击空地种下待办，保存后对应作物出现在田里；点击作物查看该待办，并可直接完成、收获。点击屋子进入厨房场景，点击箱子查看仓库，点击厨房里的灶台和冰箱进入烹饪与料理收藏，点击出口回到农场。点击鱼塘打开钓鱼小游戏，点击鸡舍或畜棚照料动物。场景入口也支持键盘 Tab 与回车操作。田里展示最近种下的 12 件未完成待办，更多计划可以点击农田标题查看；满田后仍可通过加号继续播种。

## 仓库、厨房与冰箱

仓库同时展示累计收获和当前可用数量。仓库包含作物、鱼获、鸡蛋和奶类。做饭消耗实际食材，累计获得数量不会因此减少。删除已完成的待办也不会抹去它的收获记录。

厨房展示全部 81 道原版食谱，其中 45 道可通过现有作物、鱼获、畜产与常备食材制作。未开放来源的材料会明确标出，材料不足时可查看缺少什么。大麦粉、糖、油、醋和大米是**不限量的常备食材**；食谱中的作物、鱼获、蛋和奶会按实际数量扣除，材料不足时不能烹饪。做好的料理放入冰箱。

撤销烹饪会移除对应料理并返还那次实际消耗的食材，包括“任意鱼 / 蛋 / 奶”所用的具体物品。如果想把一件已完成的待办改回未完成，它产生的作物必须仍有足够库存；食材已经用掉时，先撤销相关烹饪，再撤销待办完成。

旧版计划和设置会保留。旧版已完成的待办不会被追溯补发收获，仓库从新版本实际产生的收获开始记录。

## 鱼塘与畜棚

点击顶部鱼塘或「鱼塘 · 钓一会儿鱼」抛竿，鱼咬钩后进入收线小游戏。用鼠标或空格操作，成功后鱼获自动进入仓库。鱼塘采用休闲混合鱼池，含 61 种普通鱼及水产、3 种水草，均使用游戏原版名称和图像；不限制原版海域与季节，不含传说鱼。

鱼塘内可自行设置每天 0–180 分钟的娱乐时间（默认 10 分钟，0 为关闭）。只累计实际游玩时间，关闭、暂停或切到后台停止游玩。已用时长按本机日期保存，重开应用不会清零；调整上限也不会抹去已用时长。到限后停止钓鱼，次日重新计算。

鸡舍里有鸡和鸭，畜棚里有奶牛和山羊。点击建筑分别进入对应的动物面板，也可以在面板顶部切换住所。依次喂食、抚摸、收取，可获得原版鸡蛋、鸭蛋、牛奶和羊奶。此应用使用每日照料节奏，每只动物每天 1 份，照料进度和已领取记录都会保存，不按原游戏的饲养天数计算。

## 村民来访与桌面设置

- 「今日来访」随机展示一位角色的原版肖像和中文对白，也可以从下拉框指定角色，再听一句。对白来自本机游戏文本，过滤需要玩家姓名、选项或剧情指令才能解释的内容；不会编造人物台词。长对话可以展开，来源提示包含游戏文本键。
- 顶部窗口按钮切换小组件模式；图钉控制窗口置顶。拖动顶部标题栏移动窗口。
- 拖动窗口边缘自由调整尺寸，最小约 360 × 480；退出后再次打开会恢复上次的窗口尺寸和位置。顶部按钮只提供小窗口与宽窗口的快捷尺寸。
- 界面随窗口宽度调整，窄窗口保留种植、仓库、厨房和村民来访功能；村民对话在约 360px 宽度下也能查看，较长内容可展开。
- 关闭窗口后，点击菜单栏小鸡图标重新打开；`⌘Q` 完全退出，`⌘N` 添加待办。
- 设置中切换四季、天气、减少动态效果，或选择城市使用实时天气。未配置城市或网络不可用时会显示「装饰天气」。
- 初次启动清单为空。设置中可以主动添加带「示例」标记的计划。

## 本机游戏素材

农场与面板使用本机原版贴图，包括农舍、树木、四季地形、作物、猫、鸡、木板、纸张和复选框。基础场景从 Stardew Desk 已读取的本机 PNG 缓存导入：

```sh
sh scripts/import-game-assets.sh
```

默认缓存目录为 `~/Library/Application Support/Stardew Desk/scene/data/img`，也可把其他包含这些 PNG 的缓存目录作为参数传入。构建时缺少基础场景素材会尝试自动导入。

新版的作物数据、料理数据、中文角色对白、物品图标和肖像直接从已安装游戏的 XNB 文件提取，使用项目随附的本地读取工具，不依赖 Stardew Desk 对这些数据的缓存：

```sh
node scripts/extract-gameplay.cjs
# 游戏安装在其他位置时，传入它的 Content 目录：
node scripts/extract-gameplay.cjs '/你的游戏/Contents/Resources/Content'
```

默认读取 `~/Library/Application Support/Steam/steamapps/common/Stardew Valley/Contents/Resources/Content`，并读取同一安装下的 `StardewValley.GameData.dll` 以识别当前数据结构。导入过程只读取游戏文件，不修改安装目录。

素材导入脚本也接受第二个参数指定游戏 Content 目录：

```sh
sh scripts/import-game-assets.sh '/你的缓存/scene/data/img' '/你的游戏/Contents/Resources/Content'
```

所有生成的游戏数据与美术都放在 `web/game-assets/`，包括 `game-data.js`。此目录和 `dist/` 已被 `.gitignore` 排除。素材与对白版权归 ConcernedApe 所有；本机 App 包含个人导入的游戏内容。分享源码请运行 `sh scripts/package-source.sh`，生成的 `dist/Stardew-Journal-source.zip` 不含游戏素材、生成目录或 App。

## 数据与天气

原生应用将数据原子写入 `~/Library/Application Support/Meadow/state.json`。浏览器预览的数据保存在该浏览器的 localStorage，与桌面 App 相互独立。计划、种植选择、收获、烹饪、钓鱼用时与鱼获、动物照料记录和设置都保存在本机，设置中可导出和导入 JSON 备份。

导入先校验全部内容，再由应用内确认替换。无效备份不会覆盖现有数据。旧文件无法读取时尽量保存恢复副本；无法保存副本时暂停写入，保留原文件。

原生窗口的位置、尺寸和置顶状态另由 macOS 偏好设置保存。导入备份会替换待办、农场进度和风景设置，但保留当前窗口的置顶与小组件模式。应用不与 Apple“提醒事项”同步。

只有主动设置天气城市后才向 Open-Meteo 查询天气。查询发送城市名称或所选城市坐标，不发送待办内容，不使用系统定位。季节自动模式按北半球月份切换，也可手动选择季节。

这是可移动、可置顶的小窗口，尚未集成 macOS WidgetKit 通知中心，也不包含系统提醒、账号同步或开机自启动。

## 检查与主要文件

检查覆盖日期窗口、DST、闰年、逾期、备份导入、损坏数据保护、原生保存桥接，以及收获、钓鱼限时、每日动物照料、库存、烹饪与撤销之间的数据一致性。

主要文件：`web/app.js`（界面交互）、`web/model.js`（数据与日期、仓库和厨房）、`web/farm.js`（游戏场景）、`web/game-ui.js`（原版面板素材）、`web/villagers.js`（村民来访）、`web/fishing.js`（限时钓鱼）、`web/animals.js`（每日动物照料）、`scripts/extract-gameplay.cjs`（本机游戏数据与图像提取）、`mac/Meadow.swift`（桌面宿主）。
